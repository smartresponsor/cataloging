PowerShell tools

This directory is part of the root source-of-truth.
Embedded dot copies are projections and must not be treated as the primary editable source.

Current tools
- commanding.ps1 launches the shell menu through Git Bash or WSL.
- delta-slice-builder.ps1 builds a delta slice zip from git changes.
- repo-map-builder.ps1 builds a repository tree map.

Notes
- Scripts are written to stay useful in Windows-first environments.
- Prefer editing root scripts and exporting projections later.
