# Category RC package notes

This repository is now close to a proper RC package, but a few packaging concerns matter more than new features:

- entry documentation must be obvious from repository root
- contract documentation must be obvious from `api/`
- runbook/proof commands must be obvious from `docs/`
- historical engineering notes should remain available, but must not override current entry documents
- RC declaration must distinguish:
  - what exists
  - what is proven
  - what is still intentionally not promised

This file exists to keep that packaging discipline explicit.
