= Cataloging CategoryBanner Entity Rename

This patch removes the generic `App\Cataloging\Entity\CategoryBanner` runtime class from `Cataloging`.

== Refactor

----
src/Entity/CategoryBanner.php
----

is renamed to:

----
src/Entity/CatalogCategoryBanner.php
----

and the class is renamed from `CategoryBanner` to `CatalogCategoryBanner`.

== Reason

The combined App Kernel cannot load multiple components that declare the same FQCN:

----
App\Cataloging\Entity\CategoryBanner
----

Both Cataloging and Vendoring now use component-scoped class names.
