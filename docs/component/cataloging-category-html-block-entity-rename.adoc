= Cataloging CategoryHtmlBlock Entity Rename

This patch removes the generic `App\Cataloging\Entity\CategoryHtmlBlock` runtime class from `Cataloging`.

== Refactor

----
src/Entity/CategoryHtmlBlock.php
----

is renamed to:

----
src/Entity/CatalogCategoryHtmlBlock.php
----

and the class is renamed from `CategoryHtmlBlock` to `CatalogCategoryHtmlBlock`.

== Reason

The combined App Kernel cannot load multiple components that declare the same FQCN:

----
App\Cataloging\Entity\CategoryHtmlBlock
----

Both Cataloging and Vendoring now use component-scoped class names.
